# Monetization — Feature Splits

Per-tool free vs Pro breakdown. Free stays fully functional in-browser;
Pro removes limits and unlocks advanced output/options.

## PDF Splitter (`/tools/pdf-splitter`)

| Area | Free | Pro |
|------|------|-----|
| Split mode | All pages, Custom ranges | + Every N pages (grouping) |
| Download | Individual files | + ZIP bulk download |
| File size limit | Up to 20 MB | Unlimited |
| Settings persistence | — | Saved split settings per browser |
| Processing | Browser queue | Priority processing |

## Image to PDF (`/tools/image-to-pdf`)

| Area | Free | Pro |
|------|------|-----|
| Images per job | Up to 5 | Unlimited batch |
| Page size / margin / fit | A4, Letter, Legal | + custom size, fit-image |
| JPEG re-encode | Quality 40–100 | + lossless full-color |
| File size limit | Up to 20 MB | Unlimited |

## PDF Compressor (`/tools/pdf-compressor`)

| Area | Free | Pro |
|------|------|-----|
| Presets | Balanced only | Lossless, Maximum, Custom |
| Raster re-encode | 72 DPI cap | Full resolution |
| Batch | Single file | Multi-file queue |
